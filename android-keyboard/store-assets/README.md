# Google Play artwork

- `tambola-keyboard-icon-512.png` is a 512 × 512 RGBA export of the app's existing magenta and cream T mark.
- `tambola-keyboard-feature-1024x500.png` is a 1024 × 500 RGB feature graphic. The phone panel is an illustration, not an Android or WhatsApp screenshot.
- Regenerate both PNGs with Python 3 and Pillow by running `python3 render_assets.py` from this directory. Pillow is only needed for artwork regeneration; it is not an app dependency.

Capture current Android 16 screenshots separately from the release candidate before uploading the listing.
