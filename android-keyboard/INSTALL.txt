TAMBOLA KEYBOARD 1.1 - ANDROID 8 OR NEWER

ONE PHONE. TWO TAPS PER NUMBER.

SET UP ONCE
1. Open Tambola-Keyboard-1.1.0.apk on the phone with WhatsApp. Install it.
   If updating, install over the old app. Do not uninstall it first.
2. Open Tambola Keyboard. Tap Help me set it up.
3. Tap Enable Tambola Keyboard. Turn it on, then return.
4. Tap Choose Tambola Keyboard. Select it.
5. Tap Practice safely. Tap the message box, then Next number.
   Tap Clear practice message to try again. Nothing is sent in practice.

PLAY
Open your WhatsApp group. Tap the message box. Choose Tambola Keyboard.
Tap NEXT NUMBER, then WhatsApp SEND. Repeat for every call.
The number appears as digit emojis. Players mark their paper tickets.
Only the host needs this app.

USEFUL BUTTONS
Call: return to Next number.
Hear again: hear the same number on this phone.
Insert again: put the same number in an empty message box.
ABC: change to your normal keyboard to type a message.
Board: see all called numbers.
Voice: choose English, Hindi or Hinglish; turn speech on/off.
Swipe up inside the keyboard if a button is lower down.

SHARE A PICTURE OR VOICE CLIP
Send the current message first. Tap Share in the keyboard.
Choose Number picture, Recent numbers picture, Board picture or Voice clip.
If a chooser appears: choose WhatsApp, your group, then Send.
Otherwise check the attachment preview and tap Send.
Playing sound aloud does not send it to the group.

WINNERS (OPTIONAL)
Tap Winners, then Players & prize amounts. Add names once.
After checking the paper ticket, choose the prize and up to two winners.
Default total prize: Rs 10. Two winners receive Rs 5 each.
Tap Save winners. Use Insert announcement, then WhatsApp Send.
At the end: Winners -> Insert all results -> WhatsApp Send.

NEW GAME
Board -> Undo / New game -> Start a new live game.
Share results first. Player names and prize settings are kept.
Undo and New game do not remove WhatsApp messages already sent.

NUMBERS ARE SAVED ON THIS PHONE
Use this keyboard as the only caller for the whole game.
The website runs a separate game. Practice is separate too.
Try your own WhatsApp chat first, then start a new game for group play.

No Internet, contacts or microphone permission. No automatic sending.
Android displays its standard warning when enabling a keyboard.
