# Tambola Jalsa · Beta v48 — clearer live-game setup

This update includes the v47 Tambola and Bingo online multiplayer redesign. Both quick games require at least two real players; the service never adds computers to these new tables and returns entry coins when no opponent joins within two minutes.

For a fresh installation, the home now says to create a player before joining a live table. Tapping either game card opens player setup when no player exists, making the first step clear. Existing players continue straight to their selected game.

The PC game service must be online. This beta uses virtual coins only, with no cash prizes or payments. Android asks before installing the update and retains app data across the compatible package update.
