# Waiting-table recovery — 27 September 2026

When a saved friends lobby lost its connection, the previous layout added a largely empty controls panel. In normal English landscape this reduced the table width from about 651 dp to 403 dp and stacked its invitation and roster. Its disabled start button could still say “Everyone’s here · Start game”, based on the last confirmed roster.

Alpha30 keeps recoverable connection status inside the waiting table. It explains that the displayed table is the last confirmed state, provides Reconnect now, and labels the disabled host action Waiting for connection. The table keeps its width. Connecting has its own message; live state restores the normal host/guest hint. Quick-play waiting also uses the inline notice. Saved pending requests retain their separate exact-retry control, and session/storage failures retain reset controls.

The implementation follows the game UI frontend skill's contextual-feedback and readable-layout guidance using the existing palette. Messages wrap without a line cap, the reconnect target is at least 48 dp, and a polite accessibility live region announces status changes. Actual TalkBack behavior is not established by the semantics check. No server, economy, rule, purchase or reconnection protocol changed.
