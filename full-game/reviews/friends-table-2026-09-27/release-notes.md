Play Tambola together over the Internet using a private friends’ table.

1. Install this APK over the previous Internet Beta to keep your profile and coins.
2. Choose your tickets, then **Play with friends → Create table**.
3. Tap **Invite friends** or copy the table code. Friends choose **Join with code**.
4. The host taps **Start game** once everyone is there.

Tables support 2–8 people. Friends’ rooms contain only invited players; quick play remains available separately. Leave before starting for a full refund. Unstarted rooms close and refund everyone after 15 minutes. The new landscape lobby shows your code, connected friends and Start together, with English and Hindi support.

The app uses free virtual coins with no cash value. Your game is hosted temporarily on the developer’s PC, which must stay awake, signed in and online. This is a small-group prerelease using development signing, not a Play Store release. Direct invitation links are not supported yet; use the shared code. Each new friends round currently needs a new table code.
