# Tambola Jalsa · Beta v50 — livelier play arenas

- Tambola uses the full ticket stage for a single ticket on shorter screens. Taller screens pair it with a recent-call display. Each ticket now shows prize progress beside its claim button, and the live feedback strip counts marked and ready-to-dab calls.
- Bingo cards keep square, aligned cells. Called numbers waiting for a mark glow gold, while marked numbers remain mint. The live scoreboard is compact enough to keep the claim button visible, and a pattern chase shows progress toward each prize on the current card.
- English and Hindi arena text is included. The 10-second quick-table and clearly identified computer-player behavior from v49 continues.

This beta uses the existing Android package and signing identity. The app connects to the existing online Tambola Jalsa service.
