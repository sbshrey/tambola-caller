# Stable friend invitations — 27 September 2026

Alpha30 shares invitation pages on the current temporary tunnel hostname. A tunnel restart invalidates those web addresses even if a table's code is still valid. Alpha31 instead shares `https://sbshrey.github.io/tambola-caller/friends/#CODE`. Sharing no longer waits for a server-directory lookup. The app continues to use its trusted directory for actual game connections, and the existing table deadlines and purchase confirmation remain authoritative.

The independent static page offers English/Hindi, a grouped code, Copy code with a selectable fallback, an explicit package-restricted Android intent, and an APK download. The fragment is validated as exactly eight canonical code characters. Unknown parameters, encoded/non-ASCII codes and extra fragment content remove the app-launch action. Changing the fragment refreshes the displayed code and intent together. No automatic launch, room lookup, credentials, analytics or purchase occurs. Its CSP blocks network connections, and the code fragment is absent from network requests.

The Game UI Frontend and Game Playtest skills guided the concise mobile hierarchy, readable text, keyboard controls and actual browser verification. The normal 360-pixel layout shows Open in app in the initial viewport. At 200% text, English/Hindi content remains scrollable without horizontal overflow and action targets remain at least 48 pixels.
