# Tambola Jalsa · Beta v47 — live multiplayer and game presentation

Tambola and Bingo now open from a shared game home with distinct 90-ball and 75-ball artwork. Both choices lead to online tables. Bingo's local practice action is removed from the player flow.

New v47 quick tables wait for at least two real people before the first call. The server does not add computer seats to those tables. If a second player has not joined within two minutes, the waiting room closes and returns the entry coins. Friends tables keep their explicit host start and two-player minimum. Existing v44 rounds remain recoverable under their original rules.

Bingo now uses the same dark game palette as Tambola, with a visible live-call ball, call progress, recent calls, player count, and claim action. Its waiting room shows the human-player count and a clear waiting state. The home and Bingo layouts adapt to landscape and large text, with English and Hindi copy.

This beta still requires the PC game service to be online. Entry coins are virtual; no cash prizes or payments are involved. Players confirm Android's update installation. This release does not silently replace the installed app.
