# Friend invitations — 27 September 2026

Alpha27 required a recipient to install the APK and type a code. Alpha28 adds a shared web invitation with an English/Hindi landing page, a download fallback and an explicit Android app-opening button. The app reviews the code, ticket quantity and virtual-coin cost before buying. The ordinary share sheet still requires the user to choose a recipient and send; no messages were sent by this task.

This follows the [hands-on rival review](../readable-results-2026-09-27/README.md), where a direct room URL restored the rival's running room but the code-entry path rejected it. Our invitation into an already purchased friends table offers a return action without charging again. This is a specific usability improvement, not a claim that every rival or device has been beaten.

## Implementation

- A strict beta-only `tambola-beta://friends/CODE` parser accepts only an eight-character canonical code. Links cannot specify an API origin, profile, token, command or ticket count. Arbitrary extras are cleared by the existing activity lifecycle handling. Legacy private-room links retain their separate path.
- The confirmation dialog shows explicit quantity/cost, respects wallet affordability and prevents purchases while loading, busy, pending or occupied. Opening/dismissing an invitation never submits a new game command. A successful explicit purchase uses the existing durable request/receipt flow; matching room acknowledgement closes the review.
- Invite friends obtains a link from the same validated publisher directory, without a room lookup or credentials. The prepared message always retains a code and download fallback if resolution fails.
- The gateway serves `/friends/CODE` locally with English/Hindi text. Android `intent:` anchors select the beta package and use a GitHub release fallback. There is no automatic launch, JavaScript, external asset, analytics, room disclosure or reflected request host. A restrictive CSP, no-store and no-referrer headers are verified.
- The game UI skill guided the purple/cream/coral/gold visual design and large touch targets. Computer-use browser review checked desktop and a 390×844 viewport in both languages. The browser screenshots use the sample code `ABCDEFG2`; they are not a live game invitation. Before replacing the public gateway, a read-only database count found zero unfinished unexpired rooms. The previous helper files were retained under the protected host's `upgrades/alpha28-20260927-101229` folder. The game service, databases and schema were not replaced. Restarting the public bridge changed its Quick Tunnel hostname; GitHub's raw-file CDN temporarily served the previous directory entry despite the branch containing the new one. Public acceptance waits for normal directory resolution rather than overriding the endpoint.

Links are temporary: a tunnel restart invalidates the old web URL, while a still-valid code can be entered in the app. The PC must remain awake, signed in and online. This is a prerelease using development signing. Physical-phone mobile-data/browser handoff, touch/audio/frame performance, purchase-burst latency and production deployment remain open.
